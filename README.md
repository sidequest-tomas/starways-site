# starways-site

Starways landing page, press kit and privacy policy. Static files, deployed with GitHub Pages from the main branch root.

- `index.html`: landing page and press kit (EN/SV toggle, press kit always in English)
- `privacy.html`: privacy policy (EN and SV), linked from Google Play
- `img/`: screenshots (demo mode of the web prototype; replace with Android app screenshots)
- `fonts/`: self-hosted fonts, so the site makes no third-party requests

Placeholders to fill before launch: `[opt-in link from Play Console]`, `[date]`, `[name, email]`.
